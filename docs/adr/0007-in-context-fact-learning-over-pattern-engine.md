# ADR 0007 — 事实底表轻量自然迁移与反过度拟合 (In-Context Fact Learning over Heavy Pattern Engine)

## 状态
已采纳（2026-11-04，设计决策）

**v2.9.1 实现状态：部分实现。** 已有事实记录与上下文读取能力；尚无 Worker 派发及向 `TaskEnvelope` 注入跨目标事实的实现。下文保留完整目标设计，经验迁移效果不属于本版本保证。文中 IP、产品与立足点记录均为虚构示例，不代表真实资产、秘密或实测。

## 背景
在多主机内网渗透中，一个关键议题是如何将在 Host A 上验证的突破经验（如 Shiro 默认 Key、特定的 WebShell 上传姿势）复用到同架构的其他兄弟主机（Host B/C/D）。备选方案包括：
1. 编写重型代码层算法，将漏洞自动抽象为强规则式的“模式卡片”并全网强制广播点射；
2. 保持轻量务实，仅在事实底表中如实追加确凿的立足点记录，依赖大模型自身的 In-Context Learning（上下文学习）进行跨目标经验迁移。

## 决策
我们决定采用 **事实底表轻量自然迁移原则 (In-Context Fact Learning over Heavy Pattern Engine)**：
1. **坚决不造重型模式抽象轮子**：
   - 不编写容易引发死锁与逻辑漏洞的重型全网广播匹配引擎；
   - 避免“刻舟求剑”式过度拟合：Host A 上生效的 Exploit 可能因为微小的补丁或后置数据库差异在 Host B 上失效，若代码层强塞该姿势，极易诱导模型在失败后草率放弃，导致同族目标大面积漏报；
   - 避免“一次误报全网自爆”：防止因单点偶发网络波动或蜜罐假回显引发全网并发告警风暴；
2. **轻量化自然语言底表提示**：
   - 当 Host A 攻陷后，事实底表中清晰追加客观事实：`[重大立足点] 主机 10.10.1.15 (泛微OA) 成功利用 Shiro 默认 Key 突破至 RCE`；
   - 派发给 Host B 的任务信封中仅引用该客观事实，由大模型自发优先进行同指纹试探；若不中，模型自然平滑退回常规探针，既享受迁移红利，又零死代码绑架风险。

## 后果与权衡
- **积极影响**：
  - 架构极致轻量，避免了 400+ 行复杂且脆弱的规则引擎代码；
  - 杜绝了先入为主的刻舟求剑式误杀漏报；
  - 保持了攻防体系对真实复杂环境的动态适应弹性。
- **代价与约束**：
  - 经验迁移依赖大模型对底层事实记录的阅读与理解，需保证事实底表条目简练精准。
